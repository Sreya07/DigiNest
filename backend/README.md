# DigiNest Backend

Zero-dependency mock API for the DigiNest rebuild.

## Run

```bash
npm start
```

The server listens on `http://localhost:4000/api`.

## Routes

- `GET /api/health`
- `GET /api/dashboard`
- `GET /api/documents`
- `GET /api/documents/:id`
- `POST /api/documents`
- `GET /api/consents`
- `PATCH /api/consents/:id/status`
- `GET /api/history`
- `GET /api/reminders`
- `GET /api/family`
- `GET /api/life-events`
- `GET /api/life-graph`
- `POST /api/share-links`
